# Storage Bros — Idaho Falls (redesign mockup)

A one-page redesign mockup for Storage Bros self storage at 2268 E Iona Rd,
Idaho Falls, ID. Built as a pitch to show what the site could look like
instead of the shared corporate template it currently runs on.

Real facility photos, real hours, real unit pricing, real address. No
fabricated reviews, ratings, or testimonials.

This is a mockup only — it's marked `noindex` and isn't meant to be found by
search engines or confused with the business's actual live site.

## Stack

- Vite + React
- Tailwind CSS v4
- Framer Motion for scroll reveals
- IBM Plex Sans / IBM Plex Mono (self-hosted via Fontsource)

## Local dev

```
npm install
npm run dev
```

## Build

```
npm run build
```

Deploys automatically to GitHub Pages on push to `main` via the workflow in
`.github/workflows/deploy.yml`.
